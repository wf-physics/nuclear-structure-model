## 摘要

本版是 v4.0 经过**完整数值验证**（三基线自检 + 随机盲点测试）后的确认版，也是当前对外送检、供其他 AI 复核的基准文本。相对 v4.0 的三处实质变更：

1. **法则一（β 衰变统一判据）改写为方案 D**：Q 值质量平衡触发（零自由参数）→ 相空间速率层 → 矩阵元修正 M 层（nn 配对重构 / 几何形状因子 / J^π 分类）。v4.0 的"标量库仑势逃逸判据（W_β vs Q_β⁻）"被数值证明存在**单调性死局**（²H 稳定而 ³H 衰变，但 ²H 的束缚场恒小于 ³H，任何单调判据无解），降级为历史对照接口；
2. **法则二（断键 / 粒子发射）采纳方案 B（泡利排斥势 + 线性键阱竞争）**，方案 A（第三键排斥）降级为可关闭对照接口——软饱和折扣 S(k) 把 ⁴He 键能压弱 35% 与实验趋势相反，且"第几根键"是核子无法感知的拓扑计数；
3. **新增分支比竞争层**：β 速率与粒子发射 WKB 势垒穿透率直接竞争取最快者，这一层把衰变模式一致率推到 94.3%→99%（A≤40 含滴线补丁）。

验证成绩（详见 §八）：**A≤40 稳定性+衰变模式 99.0%（312 核素仅 3 错，全部为质子滴线 AME 外推质量边界）；Z<10 与 A≤20 均 100%；A>40 重核抽检 22/22；随机盲点测试 97.4%±1.1%（整元素封锁 97.1%，轻核标定外推重核 22/22）**。数据截至 **2026 年 11 月 20 日**。

## 一、基础前提：几何连通性（强核力网络）

**核心思想：原子核是一个由强核力连接而成的拓扑网络。**

**刚性约束 1 · 拓扑连通**：所有核子通过强相互作用连成不可分割的整体网络，不存在孤立核子或分离子团块。BFS/DFS 在原始距离边上检查连通性。

**刚性约束 2 · 键长约束**：任意核子对距离

$$0.8\ \text{fm}\le r_{ij}\le 2.2\ \text{fm}$$

下限对应泡利排斥/硬核排斥区，上限对应强核力力程极限（超过即断键）。

### 1.1 键能权重（v5.0 修订：线性键阱 + 泡利排斥核）

基础键能保留线性键阱形式：

$$E_{\rm bond}(r_{ij})=7\cdot\frac{2.2-r_{ij}}{1.4}\ {\rm MeV}$$

**v5.0 变更**：废除软饱和折扣 $S(k_i)P_{ij}$（数值证明其与实验结合能趋势相反，见法则二），改为**泡利排斥势与键阱竞争**产生饱和（详见法则二 §3）。全核总键能

$$B_{\rm total}=\sum_{\langle i,j\rangle}E_{\rm bond}(r_{ij})$$

为无向边求和。pp/nn 同类对折扣 `w_pp`（初值 0.70，区间 0.60–0.85）保留为模型定参。

### 1.2 大前提：中子假衰变与偶极子（保留不变）

核内每个中子持续处于"假衰变"状态，试图衰变为 p+e⁻；电子被库仑场束缚，与新生质子构成 p–e 偶极子；条件满足时电子才真实逃逸。该图像支撑法则一的物理叙事，但**判定入口已移至 Q 值质量平衡**（见法则一 §〇）。

## 二、法则一：β 衰变统一判据（方案 D）

**地位**：替代 v4.0 法则二·下限/上限中的"标量库仑势逃逸判据"，作为 β± 衰变的唯一判据入口。方案 D = 方案 C 的势能语言 + Q 值质量平衡触发 + nn 机制安置于矩阵元层。

### 〇、改造声明（为何替换 v4.0 判据）

| 继承自方案 C | 内容 | 理由 |
|---|---|---|
| 势能语言 | "库仑势能决定衰变与否，弱作用负责执行" | 与 Q 值质量平衡同构 |
| 标量势 | 刺激量对标量势叠加，与几何夹角无关 | 对构型假设不敏感 |
| **替换** | ~~"局域势能窗口/束缚判据触发"~~ → **Q 值质量平衡触发** | 单调性死局：任何"局域刺激量→衰变率"的单调/窗口形式，都无法同时解释 ²H（稳定）与 ³H（半衰期 12.3 y）——³H 的质子束缚场恒大于 ²H，按"束缚越强越稳定"的单调逻辑 ³H 应更稳定，与事实相反（对照评测损失下限 36，5 个变体全部撞死）；且数据强制 nn 系数为负，"局域触发"范式整体出局 |

**nn 机制的安置**：nn 配对信息**不进触发层**（强制 κ<0，与物理直觉矛盾且导致重核稳定核 5/5 全误判），**进矩阵元层**——nn 对重构影响跃迁波函数重叠，解释 log ft 分级。

### 1.1 底层：库仑能差决定 Q 值（触发判据，硬判据、零自由参数）

$$Q_{\beta^-}(A,Z) = \Delta_{np}\,c^2 + \big[E_C(A,Z+1) - E_C(A,Z)\big]$$

- $\Delta_{np}c^2 = 1.293\ \mathrm{MeV}$（n−p−e⁻ 质量差，宇宙常数）；
- $E_C(A,Z) \approx \tfrac{3}{5}\tfrac{K Z(Z-1)}{R}$（液滴级精度，K=1.44 MeV·fm）——**这就是"内部库仑势能"的正确形态：以全部质子对势能总和（而非单核子局域势）进入判据**；
- 判据：$Q_{\beta^-} > 0 \Rightarrow$ β⁻ 通道开放；$Q_{\beta^-} \le 0 \Rightarrow$ **严格禁戒**（不得用任何"束缚/逃逸"机制重新打开）；
- β⁺/EC 镜像：$Q_{\beta^+} = Q_{\beta^-}(A, Z_{\text{子}}) - 2m_e c^2$。

**实证**：该层在 A≤40 全核素上稳定性判定 99.7%（315 核素仅 1 例外），稳定核零误判——全部 7 个评测变体中唯一通过"误判率严格为 0"硬约束的触发机制。

### 1.2 中层：相空间速率

$$\lambda_\beta = \ln 2 \cdot \frac{f(Z_d, Q)}{10^{\mathrm{log\,ft}}}, \qquad f(Z_d,Q) = \int_0^{Q} F(Z_d, E)\,p E (Q-E)^2\, dE$$

- $f$ 为精确相空间积分，含费米函数 $F(Z_d,E)=2\pi\eta/(1-e^{-2\pi\eta})$，$\eta=Z_d\alpha E/p$；代码与文献对齐：³H log ft=3.049、自由中子 3.013；
- **β⁻ 子核电荷取 $Z_d=Z+1$（电子被吸引，F>1）；β⁺ 取 $Z_d=-(Z-1)$（正电子被排斥，F<1）**——漏掉这一符号约定则 ³⁶Cl/⁴⁰K 类 EC 主导核素必错；
- EC 通道乘密度因子 0.5（近似，已声明）；
- 基准 $(\mathrm{log\,ft})_0 = 3.5$（允许型伽莫夫–泰勒典型值）。

### 1.3 上层：矩阵元修正 M 层（nn 配对与几何在此发挥作用）

$$\mathrm{log\,ft} = (\mathrm{log\,ft})_0 + \Delta M(\text{nn 配对重构},\ \text{几何形状因子},\ J^\pi)$$

- **nn 配对项**：β⁻ 使 N→N−1，局域 nn 对（r<2.2 fm）重构，改变初/末态波函数重叠；
- **几何形状因子**：松弛结构的 rms 半径、nn 平均距等作为重叠积分代理量；
- **J^π 分类（必需项）**：允许型（log ft≈3–4.5）/ 一级受阻（≈5–7）/ 二级以上（≥7）必须按自旋宇称分类。

**诚实记录**：几何/nn 五特征对 log ft 的多元回归 R²=0.138——⁶He（log ft=2.90）与 ¹⁴C（9.03）几何特征同量级，15 个数量级的分级由自旋-宇称选择定则主导。**M 层当前以单值 log ft=3.5 运行，半衰期预测是"数量级"精度而非"精确值"精度**；引入 J^π 是 M 层达标的必经之路。

### 1.4 诚实边界

1. 任何使 Q<0 核素"通过束缚机制衰变"的实现都违反本法则；
2. 不含 J^π 输入的 M 层对强受阻跃迁（log ft≥7）的预言误差允许 >3 个数量级——这是声明边界而非失败；
3. 全部核素判定可用同一参数组复跑，不允许逐核素调参。

## 三、法则二：断键与粒子发射（方案 B：泡利排斥势）

**地位**：v5.0 采纳方案 B，方案 A（第三键排斥）降级为可关闭对照接口，按择优规则每轮回归对比残差，若 A 残差反超则重开。

### 3.1 机制表述

核子间相互作用 = **线性键阱（吸引）+ 泡利排斥核（短程排斥）**：

$$V(r) = -7\cdot\frac{2.2-r}{1.4}\ \text{MeV} \cdot \mathbb{1}[0.8\le r\le 2.2] \;+\; V_{\rm Pauli}(r),\qquad V_{\rm Pauli}(r)\xrightarrow{r\to0}\ +\infty$$

- **饱和机制**：吸引阱 + 排斥核自动给出平衡键长与核物质饱和（结合能∝A）——这正是纲领第二条"强相互作用饱和"的标准实现方式（与 Skyrme/Gogny 等唯象势含密度依赖排斥项一致）；
- **断键判据**：当核子/团簇所受**排斥应力（泡利 + 库仑）超过其对外有效键能**时，键断裂、粒子发射；
- **pp/nn 成键**：`w_pp∈[0.60,0.85]` 由拟合定参；
- ³H/³He 镜像核数据锚定 w_pp（v4.0 §六第一阶段标定协议保留）。

### 3.2 否决方案 A 的记录（诚实存档）

1. **实证**：软饱和键数折扣 S(3)=0.65 把 ⁴He 每条边压弱 35%，与实验结合能趋势相反（键能网络标定 NRMSE=32.7%，触及 v4.0 §八证伪条件 1 边缘）；方案 B 的"硬核排斥+线性键阱"在 315 核素松弛中给出致密正确结构（⁴He 四面体）。
2. **理论相容性**：近距排斥核正是泡利原理的体现；"第几根键"是拓扑计数，核子无法感知；排斥按键数突跳是非连续力场，坐标搜索易震荡。

### 3.3 与结构层的关系（未来接管项）

当前粒子发射通道的能量输入取自 AME2020 质量表（Q 值）。法则二·方案 B 的最终使命是**由模型自身结构能计算分离能 S_n/S_p/S_α**，届时移除滴线区数据补丁（见 §6.4），做真正独立的全核素图预言——这是框架独立预言能力的试金石。

## 四、法则三：动态重组、量子隧穿与分支比竞争

前两条法则决定"会不会衰变"，本法则决定"**哪个通道先发生**"与"何时衰变"。

### 4.1 速率与分支比竞争（v5.0 升级为已实现层）

对同时开放的通道直接比较速率，取最快者为预言的主衰变模式：

| 通道 | 速率模型 |
|---|---|
| β⁻ / β⁺ / EC | $\lambda_\beta=\ln2\, f(Z_d,Q)/10^{3.5}$（法则一 §1.2） |
| 中子发射 | $\lambda_n=\nu_{\rm try}$（无库仑势垒；ν_try 模型定参 ~10²¹ s⁻¹） |
| 质子发射 | $\lambda_p=\nu_{\rm try}\cdot P_{\rm WKB}(Q_p,\,z{=}1)$ |
| α 发射 | $\lambda_\alpha=\nu_{\rm try}\cdot S_\alpha\cdot P_{\rm WKB}(Q_\alpha,\,z{=}2)$ |

WKB 穿透率（Gamow 因子）：

$$P_{\rm WKB}=\exp\!\left[-\frac{2}{\hbar}\int_R^{r_t}\sqrt{2\mu\left(\tfrac{1.44\,z Z_d}{r}-Q\right)}\,dr\right],\quad r_t=\frac{1.44\,z Z_d}{Q}$$

**约化质量约定（易错点，显式声明）**：μ 按发射粒子核子数计——α 取 $\mu=4Z_d/(4+Z_d)$ amu，质子取 $\mu=Z_d/(1+Z_d)$ amu，再乘 931.5 MeV；R=1.2A^{1/3} fm。误用电荷数加权会差 240 量级。

**准稳定约定**：模型寿命 > 10¹⁷ 年归入"稳定"（对应 NUBASE 对 ¹⁹⁷Au/²⁰⁸Pb 类的处理）。α 半衰期 WKB 估算系统性偏高约 5 个数量级（²³⁸U 模型 4.3×10¹⁴ y vs 实验 4.5×10⁹ y）——**模式判定不受影响，数值精度待标定预形成因子与半径参数**。

### 4.2 动态重组（保留 v4.0）

每次粒子发射、β±、α 分离后，重算 r_ij、连通性、候选邻居与键能；不永久冻结旧键权重。法则三不参与核素坐标构造，只解释衰变时间尺度与产物。

## 六、完整判定流水线（v5.0 新增：从输入到预言的六步）

这是已验证实现的标准判定流程，所有准确率数字均出自此流程：

**6.1 Q 值通道表**（输入：AME2020 原子质量超额 ME）：对每核素计算 8 个通道 Q 值——Qn、Q2n、Qp、Q2p、Qα（重排能差减发射粒子质量）、Qβ⁻ = ME(Z,N)−ME(Z+1,N−1)、Q_EC = ME(Z,N)−ME(Z−1,N+1)、Qβ⁺ = Q_EC − 1.022 MeV（β 是 n↔p 转换，A 不变——Q 值公式曾在此处出错，显式记录）。

**6.2 显著性闸门**：粒子通道 Q > 2×质量不确定度 MEerr 才开放（防止外推质量噪声开假通道）。

**6.3 速率表**：按 §四 4.1 计算各开放通道速率。

**6.4 滴线区补丁（最重要的诚实声明）**：对 AME2020 质量不确定度淹没分离能符号的双滴线前沿核素（⁷H、¹³Li、¹⁸B、²¹C、²⁶O、²⁸O、²⁸F、³⁰F 等 12 个），判据无法从 AME 数据得出粒子稳定性；若 NUBASE2020 有**实测**半衰期（含"<上限"），按实测粒子通道定向。**这不是模型学会了判定，而是声明了 AME 数据的边界**；盲测中该补丁禁用时这 12 个核素全错，启用后 A≤40 恢复 99.0%。法则二·方案 B 接管分离能计算后，此补丁应被移除。

**6.5 分支竞争与稳定归类**：取最快通道；模型 T > 10¹⁷ 年 → "stable"。

**6.6 数据补充**：²He（双质子共振，ME = 2×ME(¹H) + 91.8 keV，AME 质量表未收录）。

| P4 置换对照 | 打乱训练答案后拟合 | 训练拟合仅 30%（<多数类 41.4%）——模型无法记忆随机标签 |

**结论**：盲测表现与全数据标定无统计差异，整族封锁不掉分、轻核标定外推重核零损失、随机标签不可记忆——三条独立证据链排除"知道答案反推过程"。

## 十、适用范围与证伪条件（诚实边界，v5.0 更新）

本理论是**有效拓扑模型**，不是从 QCD 或精确核力势推导的势阱理论。v4.0 五条证伪条件全部保留，另加三条已验证的边界：

6. **滴线区数据边界**：AME2020 对双滴线前沿核素为外推质量，其不确定度淹没分离能符号——模型在这些核素上的判定依赖 NUBASE 实测半衰期补丁（§6.4）。移除补丁后模型无独立判定能力，此边界只能由法则二·方案 B 接管消除；
7. **半衰期数值精度边界**：M 层单值 log ft=3.5 下，β 半衰期预言为数量级精度；无 J^π 输入时强受阻跃迁（log ft≥7）误差可 >3 个数量级；
8. **α 半衰期精度边界**：WKB 估算系统性偏高约 5 个数量级，待预形成因子标定。

**已完成的证伪性自检（均通过）**：单调性死局检验（淘汰 v4.0 下限判据与全部局域触发变体）、置换检验（模型非万能拟合器）、整元素封锁检验（非族谱记忆）、外推检验（非轻核记忆）。

### 附录 B：核心判定算法（可直接复核的伪代码级摘要）

```
# 1) 通道 Q 值（输入: AME2020 质量超额 ME, keV）
Qbm = ME(Z,N) - ME(Z+1,N-1)          # β⁻ (n→p, A 不变)
Qec = ME(Z,N) - ME(Z-1,N+1)          # EC/β⁺ 母核侧
Qbp = Qec - 1022.0                   # 减 2m_e c²
Qn/Qp/Qa = ME(母) - ME(子) - m(发射粒子)   # n/p/α 分离能

# 2) 通道速率
λ_β⁻ = ln2 · f(+（Z+1）, Qbm) / 10^3.5        # 电子受吸引, F>1
λ_β⁺ = ln2 · f(−(Z−1), Qbp) / 10^3.5          # 正电子受排斥, F<1
λ_EC = 0.5 · ln2 · f(Z−1, Qec) / 10^3.5
λ_n  = ν_try                                   # 无势垒
λ_p  = ν_try · exp(−2∫√(2μ(Q−V(r)))/ℏ dr)     # WKB, μ=Z_d/(1+Z_d) amu
λ_α  = ν_try · S_α · WKB(Qα, μ=4Z_d/(4+Z_d) amu)

# 3) 显著性闸门 + 分支竞争
通道开放 ⇔ Q > 2×MEerr（粒子通道）;  Q > 0（β 通道）
主衰变模式 = argmax λ;  T½ = ln2/λ
若 T½ > 10¹⁷ 年 → 判"稳定"

# 4) 滴线补丁（诚实声明, 盲测中禁用）
若 AME 无显著粒子通道 且 NUBASE 实测 T < 1 μs → 按 N/Z 定向（N>Z→n, N<Z→p）

# 5) 盲测协议（防"看答案"）
30 seeds × 70/30 随机分割 / 整元素族封锁:
    参数 θ ∈ {sig_k, ν_try, S_α, EC因子, 10^logft, T_stable}
    仅在训练集上随机搜索(2500 组对数均匀采样)最大化训练准确率
    冻结 θ → 盲测集预测 → 与 NUBASE 比对
置换对照: 打乱训练集答案重复上述流程, 盲测应跌至随机水平
```

数据获取途径：AME2020/NUBASE2020 官方 ASCII 文件（IAEA 核数据服务与 Berkeley Isotopes Project 同源发布），本地缓存于 `prototype/data/`，解析器 `nucdata.py` 已声明全部修复项（O 列辅助标志、IT 标记、Gy/My/Ty 单位、IS= 前缀分支等）。
