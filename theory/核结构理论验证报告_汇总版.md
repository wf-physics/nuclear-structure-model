# 核结构键能网络理论 · 验证数据汇总报告（供论文送检）

**版本**：v1.0 ｜ **日期**：2026-11-21
**理论**：基于第一性原理现象学的核结构与衰变统一框架（键能网络模型，理论法则 v5.1）
**用途**：汇总全部已完成的验证工作与逐项数据，供学界独立复核与证伪。

## 〇、报告范围与诚实声明

1. **本报告收录两类验证**：①稳定性与衰变模式判定（含完整核反应链推演）；②几何观测量（电四极矩、电荷半径、α 簇团）。
2. **结合能/分离能验证不纳入本报告**。现有结构引擎的结合能成绩（389 核素完全过 19.8%、含半过 55.0%）已如实测得并随数据存档（`big_validation_table.csv` 的 B 列），但其物理机制（井深不足、缺饱和密度项）尚未解决，属于**下一步"模型自洽能量公式体系"要解决的问题**，故不计入本报告的成绩单，避免混淆"已验证结论"与"在研问题"。
3. 所有验证均为**逐核素判定**：每项验证的完整对/错清单见随附数据文件，本报告给出全部失误核素名单与分区统计，不隐藏任何失误。
4. 判定原则（预注册于验证之前）：**数值类观测量按误差带判定**（实验有系统误差与操作误差、理论有理想化偏差，故判"误差是否合理"而非"是否相等"），符号/模式/计数类按精确一致判定。

## 一、验证一：稳定性与衰变模式判定

### 1.1 数据与判定口径

- **输入**：AME2020 原子质量表（官方 ASCII，3558 条全核素，解析后零缺失）；**对照答案**：NUBASE2020 半衰期与主衰变模式。
- **判定口径**：稳定性判对 **且** 衰变模式与 NUBASE2020 主模式一致。
- **判据链**（零自由参数触发层）：Q 值质量平衡（全部通道 β⁻/β⁺/EC/n/p/α/2n/2p 由质量过剩直接计算，Q > 2×质量不确定度才开放）→ β 相空间速率（精确积分 f(Z,Q)+费米函数，log ft 对齐 ³H 文献值 3.049 至 0.01）→ 分支比竞争（β 相空间速率 vs 粒子 WKB 势垒穿透，取最快）。

### 1.2 最终成绩（方案 D 判据，A≤40 全量 314 核素）

| 指标 | 结果 |
|---|---|
| **模式一致率（A≤40，314 核素）** | **311/314 = 99.0%** |
| 基线一（Z<10 全同位素） | **124/124 = 100%** |
| 全对最深前沿 | **A≤21 全部 137 核素零错** |
| A≤20 / A≤25 / A≤30 / A≤40 | 100% / 99.3% / 99.5% / 99.0% |
| 重核抽检（A>40） | **22/22 全通过**（稳定 8、β⁻ 7、β⁺/EC 3、α 4） |
| 无滴线补丁口径（裸判据） | Row1 优先级 α>p>n：96.8%；n>p>α：97.8% |

实验标签分布（314 核素）：β⁻ 130、β⁺/EC 65、质子发射 46、稳定 40、中子发射 32、α 1。逐核素判定存于 `prototype/results/baseline_judge.json`（314 条，每条含 exp/pred/ok）。

### 1.3 完整判错明细（仅 3 个，全部为数据边界而非判据错误）

| 核素 | 实验 | 模型 | 原因 |
|---|---|---|---|
| ²²Si | β⁺ | p | 质子滴线前沿，AME2020 外推质量（不确定度 ~600 keV）淹没 1p 分离能符号 |
| ³⁴Ca | p | β⁺ | 同上 |
| ³⁹Ti | β⁺ | p | 同上 |

### 1.4 完整核反应链推演（第一轮，v4.0 原始判据）

从 ¹n/¹H 出发的反应链生长 + 衰变推演（`chain_predict.py`）：

- **链规模**：生长树访问 356 个状态（含衰变产物回访），衰变边 **206 条**，链终点（预测稳定）**108 个**；
- **终点对照**：与实验稳定核重合 40 个，虚假终点 68 个，**漏掉实验稳定核 0 个**；
- **第一轮成绩**：稳定性判定 78.4%（双衰变核素模式一致率 96.1%，n=207）；
- **关键发现（本验证最重要的产出）**：暴露 v4.0 法则一 β 闸门的系统性缺陷——275 个不稳定核素中 68 个误判稳定（61 β⁻ + 7 β⁺/EC），误判率随 A 递增，最大漏检 β⁻ Q 值达 14.2 MeV；
- **后续处置**：该缺陷直接触发 β 衰变机制专项对照评测（§1.6），证明 v4.0 标量库仑势判据在数学上无解，进而重构为方案 D（Q 值触发），最终成绩提升至 §1.2 的 99.0%。第一轮数据作为**证伪驱动理论迭代的完整记录**一并存档（`chain_results.json`）。

### 1.5 随机盲点测试（四协议，堵死"知道答案反推"）

协议设计：①六个可调参数只在随机保留的 70% 核素上重拟合，冻结后预测盲测集；②滴线补丁全程禁用；③更严格的整元素族封锁与轻核外推重核；④打乱答案的置换对照。

| 协议 | 次数 | 结果 |
|---|---|---|
| P1 个体盲测（藏 30%） | 30 | **97.4%±1.1%**（最差 95.8%）；剔除 12 个补丁依赖核素后 **99.2%** |
| P2 整元素族封锁（藏 30% 元素） | 30 | **97.1%**（最差 93.3%）；剔除后 **99.1%** |
| P3 轻核外推（只用 A≤20 标定） | 10 | A 21–40：**96.7%**；重核 **22/22 = 100%**（²⁰⁸Pb、²³⁸U、¹⁹⁷Au、²³²Th 全中） |
| P4 置换对照（打乱答案） | 10 | 拟合标签后仅 **30.0%**（低于多数类 41.4%）——模型不具备记忆随机标签的能力 |
| 全数据重拟合参照 | 1 | 97.5%（与盲测无统计差异 → 零过拟合损耗） |

逐次数据存于 `blind_results.json`。**滴线补丁依赖的 12 个核素全名单**（诚实条款）：⁷H、¹³Li、¹⁸B、²¹C、²⁶O、²⁸O、²⁸F、³⁰F、³³Ne、³⁶Na、³⁸Na、³⁹Mg——这些核素 AME2020 为外推质量，模型声明由 NUBASE 实测半衰期定向，不计入模型判定能力。

### 1.6 β 衰变机制专项对照评测（三方案 + nn 增强）

按任务书实现三方案（A 有效运动体积 / B 夸克波函数重叠 / C 内部库仑势能阈值）+ nn 中子-中子调制增强，标定集 ⁶He/⁸He/¹⁴C/¹⁸O 等：

- **数学死局证明**：²H 稳定 vs ³H 衰变，而 ³H 质子束缚场恒大于 ²H——任何"局域刺激量→衰变率"的单调/窗口映射均无解，三方案损失函数下限 36（≈17 个数量级误差）；
- **nn 机制打破死局**：损失 36 → 0.025，但 κ 为负号且重核 5/5 误判 → 确立 **nn 进矩阵元层、不进触发层**（成为方案 D 的核心组件）；
- 脚本：`beta_schemes.py`、`run_comparison.py`、`nn_augmented.py`、`addendum_virtual_quark.py`。

### 1.7 α 半衰期与禁戒跃迁辅助验证

- **α 半衰期三修**（出射半径 R=r₀(A_d^{1/3}+4^{1/3}) + 物理尝试频率 ν=v/2R + 形变长轴，零拟合零新参数）：²¹⁰Po 0.83 vs 实验 0.379 y、²²⁶Ra 2.13×10³ vs 1.6×10³ y、²³²Th 2.53×10⁹ vs 1.4×10¹⁰ y、²³⁸U 5.09×10⁸ vs 4.46×10⁹ y、¹⁴⁴Nd 1.01×10¹⁵ y——5 核全部进入 1 个数量级内（旧模型差 5–8 个数量级）。
- **禁戒跃迁 K 桶**（J^π→禁戒度→log ft）：8 核固定考题表如实挂出，最坏误差从 17 个数量级压至 4.9（¹¹⁵In），³⁶Cl/¹⁴C/⁶⁰Co 等仍差 2–4.6 个数量级——**半衰期数值预测为在研项**，不纳入成绩单。

## 二、验证二：几何观测量（H→Ca 全量大验证，389 核素）

### 2.0 大验证设置

- **范围**：Z≤20 全部 389 个 AME 实测结合能核素（非抽检）；
- **结构生成**：逐核素 L-BFGS + basin hopping 全局优化（scipy 标准实现），参数 (C=12, r_eq=1.608, r_min=1.4 fm) 由标定四核（²H/³H/³He/⁴He）网格扫描预注册选定，验证前冻结；
- **实验数据**：电荷半径 IAEA 官方汇编（Angeli & Marinova）、电四极矩 IAEA 官方推荐值表（Stone）、α 簇团为模型内生判定（无实验对照表，按模型定义判）；
- **逐核素清单**：`big_validation_table.csv`（389 行 × 21 列，每行含四项判定 过/半/不过）。

### 2.1 电四极矩 Q_s（65 个有实验值核素，全量对照 IAEA 推荐值）

**判定带**：符号一致且数量级差 ≤5 倍 = 过；符号一致但幅度超带 = 半过；符号不符 = 不过。

| 判定 | 数量 | 占比 |
|---|---|---|
| 过 | 34 | 52.3% |
| 半过 | 11 | 16.9% |
| **含半过合计** | **45** | **69.2%** |

**全部 20 个失误核素**（检验"失误重核居多"假设——成立，重核占 60%）：重核(Z 15–20) 12 个：S-33、S-35、Cl-35、Cl-36、Cl-37、Ar-35、Ar-39、Ar-41、K-40、Ca-41、Ca-43、Ca-49；中核 3 个：Na-26、Na-27、Mg-29；轻核 5 个：²H、⁶Li、⁷Li、⁹Li、¹⁷O。
**11 个半过核素**（符号对、幅度超带）：¹²B、¹⁹O、²¹F、²¹Na、²²F、²⁵Na、³⁷K、³⁹Ca、⁴¹K、⁴⁵Ca、⁵¹Ca。

### 2.2 电荷半径 r_ch（97 个有实验值核素）

**判定带**：模型/实验 ∈ [0.7, 1.3] = 过。

| 判定 | 数量 | 占比 |
|---|---|---|
| 过 | 64 | **66.0%** |
| 不过 | 33 | 34.0% |

失误 33 个的**结构化归因**（非随机散布）：
- **26 个系统性偏小**（比值 0.35–0.70，集中 Z≤9 轻核区：²H/³H/³He/⁴He 0–0.48、⁶Li–¹²C 0.37–0.70）——模型轻核过度紧致，缺量子零点胀大效应；
- **7 个异常偏大**（Ar-32 11.63 fm、Ca-39 10.11 fm、Ca-42 7.23 fm 等，比值 1.3–3.5）——盆地跳跃落入未收敛构型的松弛伪影，属算法残留问题；
- 全体中位比值 0.794，均值 0.874——总趋势轻度偏小 ~20%。

### 2.3 α 簇团（N=Z 4n 标准链 10 核，模型内生判定）

**判定**：识别出的 2p2n 四面体子构型数 ≥ 理想簇数（A/4）的 50% = 过。

| 核素 | 识别/理想 | 判定 |
|---|---|---|
| ⁴He | 1/1 | ✅ |
| ⁸Be | 1/2 | ✅ |
| ¹²C | 2/3 | ✅ |
| ¹⁶O | 2/4 | ✅ |
| ²⁰Ne | 4/5 | ✅ |
| ²⁴Mg | 4/6 | ✅ |
| ²⁸Si | 4/7 | ✅ |
| ³²S | 3/8 | ❌ |
| ³⁶Ar | 3/9 | ❌ |
| ⁴⁰Ca | 5/10 | ✅ |

**正确率 8/10 = 80%**。⁴He–²⁸Si 链全部通过，失效点在 A≥32（库仑拉伸 + 大核欠束缚导致构型畸变）。α 子结构比例 50–70% 是几何架构类理论相对液滴/球壳模型的**独门解释项**（两者均无 α 簇团机制）。

## 三、辅助与历史验证记录

1. **外部评审四项自检**（v5.1）：刺 2 坐标 E_C vs 液滴式（坐标式 ρ=−0.36 劣于液滴 −0.55，如实采纳"坐标引擎对 Q 值不可靠"）、刺 4 α 三修（上节）、刺 5 禁戒桶、刺 6 法则二四点自检（⁴He 局域库仑 1.77≈³He 1.73 而 B/A 差 2.8 倍 → 局域应力判据证伪，法则二改全局 S_x 判据）。
2. **键能网络观测量公式体系**（自研公式四定律检验）：L1 表面律 B=a_v A−a_s A^(2/3) 拟合 R²=0.84，**a_s/a_v=1.13 vs 液滴 1.08（一致到 5%）**——Weizsäcker 形式由键饱和推出而非输入；L4 库仑标度 a_c=0.46（液滴 0.71）；L2 奇偶配对模型内未自发出现（实锤缺口，待 M 层补配对项）；L3 分离能趋势被松弛噪声淹没。
3. **历史轮次**（已被大验证取代，存档备查）：早期 13 核几何表（Q₀ 符号 9/13）、引擎 v2.2 三重约束扫描（9 组网格）、第一轮链式推演（§1.4）。

## 五、结论

- **衰变判定**：A≤40 全量 99.0%、Z<10 与 A≤20 100%、重核抽检 22/22，且经四协议盲测确认预测力来自规律而非记忆（置换对照 30% < 多数类）；
- **几何观测量**：α 簇团 80%、电四极矩含半过 69.2%、电荷半径 66.0%——几何架构类理论的独门解释项拿到全量量化数据；
- **下一问题**（已立项未完成）：模型自洽的结合能/分离能公式体系（含井深与密度饱和项修订），完成后将重跑本报告全部几何与能量验证并出具 v2.0 报告。
